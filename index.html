The problem

Swarms are cheap. Interceptors are not.

Small drones now arrive in groups of tens. Firing one missile at each one is costly, slow to reload and hard to scale. Air defence needs an answer that treats a swarm as an area rather than a list of single targets.

Area, not point

One round places a pattern across the swarm's path, so several targets can be engaged by a single shot.

Uses existing guns

Designed around a 120 mm artillery system, so units can use crews, logistics and fire control they already have.

Inert payload

No high-explosive fill in the carrier body. The payload is plastic spheres, which keeps handling and storage simpler.

Flagship product

Kinetic counter-drone roundK-CWD 120

A purpose-built carrier shell for counter-drone work. It travels to the intercept point like any artillery round, then releases its payload rearward so the spheres spread into a broad, even pattern.

  • Calibre120 mm carrier, base-ejection canister design
  • PayloadAbout 2,000 inert plastic spheres held in an ordered matrix
  • FuzePrecision time fuze, set from the radar track before firing
  • RoleArea defence of bases, convoys and critical infrastructure

Sequence of operation

From breech to kinetic net

Scroll through the three stages. The model beside them follows along.

STAGE 01 / 03T+0.0 s
STAGE 01

Load an inert round

The carrier body holds no high-explosive fill, so the round is handled and loaded like a practice shell. The crew sets the time fuze from the fire-control solution and loads it into the breech.

STAGE 02

Release in flight

At the set time the fuze functions. The payload is pushed out rearward through the base while the shell body carries on, so the spheres leave intact instead of being shattered by a detonation.

STAGE 03

The pattern opens

The shell's spin throws the spheres outward. Combined with the rearward release, this forms a wide, layered pattern across the swarm's path, aimed at rotors, airframes and optics.
